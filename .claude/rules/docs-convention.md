# Documentation Convention

- `docs/plans/STATUS.md` is the master index of all plans. Update it when plan status changes.
- Each plan lives in `docs/plans/<name>.md` with a `Status: **X**` line at the top.
- Valid statuses: Not Started, In Progress, Complete, On Hold.
- Research documents go in `docs/research/`.
- When completing a plan or starting a new one, update both the plan file and STATUS.md.
