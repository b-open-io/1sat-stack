# Module Documentation Template

Each package under `pkg/` should have a `README.md` following this structure.
Not every section is required -- skip what doesn't apply.

---

## Template

```markdown
# {Package Name}

## Purpose

One paragraph. What does this module do, and why does it exist?

## Concepts

Key ideas a reader needs to understand before using this module.
Define terms, explain the data model, describe how the module fits
into the broader system.

## Configuration

Relevant `config.yaml` options. Show the YAML structure with defaults
and explain each field.

## Examples

Practical curl, fetch, or Go snippets showing real usage.
Use the production API URL where applicable.

## See Also

- Links to Swagger endpoints
- Related packages
- External references
```
